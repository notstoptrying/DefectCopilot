# 热轧钢板表面缺陷判定标准

文件编号：Q/HM-ZL-2025-01
适用范围：1420 热连轧产线、1780 热连轧产线生产的低碳钢与低合金钢热轧卷板（Q235B、SPHC、Q345B、DP590）。
生效日期：2025-03-01

## 1 判定总体要求

1. 所有表面缺陷判定以「在线表检仪粗判 + 质检员复判」两级确认，争议时由技术组仲裁。
2. 判定结论分为 A 级（轻微）、B 级（中等）、C 级（严重）三档，等级直接决定处置方式。
3. 单卷缺陷面积占比超过 1.5% 时，必须整卷隔离，不得直接进入下一工序。
4. 同一批次连续 3 卷出现同类 B 级及以上缺陷，判定为批量质量异常，触发 8D 流程。

## 2 六类典型缺陷定义与分级

### 2.1 划痕（Scratch）

形态特征：细长直线状或弧形沟槽，方向多与轧制方向平行，或与辊道、导板接触方向一致；沟槽两侧常见翻边毛刺，金属光泽明显。

- A 级：单条长度 ≤ 50 mm，宽度 ≤ 0.5 mm，面积占比 ≤ 0.3%，允许修磨后交货。
- B 级：单条长度 50–200 mm，或深度可用指甲感知，面积占比 0.3%–1.5%，需切除缺陷段或降级销售。
- C 级：单条长度 > 200 mm，或连续 5 条以上平行分布，面积占比 > 1.5%，判废或改判为次品卷。

典型成因：辊道划伤、导板磨损、卷取机夹送辊异物、吊运磕碰、开卷机压紧力过大。

### 2.2 裂纹（Crack）

形态特征：不规则锯齿状或网状开裂，端部尖锐，多沿晶界扩展；横向裂纹常位于板宽边部 50 mm 以内，纵向裂纹多与连铸坯原始缺陷对应。

- 任何肉眼可见裂纹一律不低于 B 级，不允许修磨后按原级别交货。
- 贯穿性裂纹、分叉裂纹、长度 > 100 mm 的边部横向裂纹，直接判 C 级。
- 裂纹类缺陷必须切除缺陷段，切除长度按「缺陷长度 + 前后各 200 mm 余量」执行。

典型成因：连铸坯角部横裂、加热温度过高导致晶界弱化、轧制压下量分配不当、矫直机应力集中。

### 2.3 夹杂（Inclusion）

形态特征：点状或条带状非金属夹杂物，颜色多为灰黑、淡黄或褐色，边缘模糊，无金属光泽；条带状夹杂沿轧制方向拉长。

- A 级：单点最大尺寸 ≤ 3 mm，且每平方米少于 5 处。
- B 级：单点尺寸 3–10 mm，或成簇分布但总面积占比 ≤ 0.5%。
- C 级：单点尺寸 > 10 mm，或大面积条带状分布，面积占比 > 0.5%。

典型成因：钢水纯净度不足、中间包覆盖剂卷入、结晶器保护渣卷入、连铸拉速波动。

### 2.4 麻点（Pitted Surface）

形态特征：密集细小凹坑，直径 0.2–2 mm，深度浅，成片分布，酸洗后呈暗灰色麻面。

- A 级：密度 ≤ 10 个/dm²。
- B 级：密度 10–30 个/dm²，或局部连片但面积占比 ≤ 1%。
- C 级：密度 > 30 个/dm²，或连片面积占比 > 1%。

典型成因：除鳞不净导致氧化铁皮压入后脱落、轧辊表面粗糙度超标、乳化液或冷却水腐蚀、酸洗过度。

### 2.5 氧化皮压入（Rolled-in Scale）

形态特征：不规则黑褐色斑块，压入基体内部，酸洗后仍残留黑色条痕，手感凹凸不平，边界呈锯齿状。

- A 级：面积占比 ≤ 0.2%，且深度不可探及。
- B 级：面积占比 0.2%–1%，或深度可探及但未贯穿。
- C 级：面积占比 > 1%，或成条带状贯穿整卷。

典型成因：粗轧除鳞水压不足、除鳞喷嘴堵塞、加热炉内氧化气氛过强、在炉时间过长。

### 2.6 斑块与色差（Patch）

形态特征：大面积浅色或暗色区域，无明显深度，边界过渡平缓，多见于卷板中部或层流冷却水嘴正下方。

- A 级：单块面积 ≤ 0.5 m²，色差轻微，不影响涂装。
- B 级：单块面积 0.5–2 m²，或同卷出现 3 块以上。
- C 级：单块面积 > 2 m²，或贯穿整卷宽度。

典型成因：层流冷却水量不均、卷取温度控制偏差、乳化液残留、板面局部氧化。

## 3 面积占比计算方法

1. 面积占比 = 缺陷区域像素总数 ÷ ROI 像素总数 × 100%。
2. ROI 取卷板宽度方向中间 80% 区域，长度方向取缺陷所在 1 米标距段。
3. 目视判定与图像判定偏差超过 10% 时，以图像判定结果为准。
4. 多类缺陷并存时，按「最高等级缺陷」定级，其余缺陷在工单备注中逐项列出。

## 4 判定流程

1. 在线表检仪输出缺陷候选区域与初步分类，置信度低于 0.6 的候选框标记为待复核。
2. 质检员在复判台逐卷确认，必要时切取试样做金相或酸洗验证。
3. 复判结论写入质量工单，同时上传缺陷图片与检测框坐标。
4. 判 C 级或批量异常时，立即通知值班调度与工艺工程师，30 分钟内到场确认。

## 5 记录与追溯要求

1. 每卷必须留存：卷号、钢种、缺陷类型、等级、面积占比、缺陷位置（边部/中部/全长）、检测时间、判定人。
2. 缺陷图片保留周期不少于 24 个月，用于模型迭代与客户追溯。
3. 工单编号规则见《质量工单填写规范》。
