# 质量工单填写规范

文件编号：Q/HM-ZL-2025-06

## 1 工单编号规则

格式：`QT-产线代号-YYYYMMDD-序号`

- 产线代号：L1420（1420 产线）、L1780（1780 产线）
- 序号：三位，当日从 001 开始
- 示例：`QT-L1420-20260812-003`

## 2 必填字段

| 字段 | 说明 | 取值示例 |
| --- | --- | --- |
| 工单编号 | 按规则自动生成 | QT-L1420-20260812-003 |
| 卷号 | 钢卷唯一标识 | 1420A2635012 |
| 钢种 | 牌号 | SPHC / Q235B / DP590 |
| 缺陷类型 | 六类之一 | 划痕 / 裂纹 / 夹杂 / 麻点 / 氧化皮压入 / 斑块 |
| 缺陷等级 | A / B / C | B |
| 面积占比 | 百分比，保留两位 | 1.24% |
| 缺陷位置 | 边部 / 中部 / 全长 | 边部（距边 60 mm） |
| 疑似根因 | 按根因对照表选 | 除鳞水压不足 |
| 处置方式 | 修磨 / 切除 / 降级 / 判废 | 切除 |
| 判定人 | 质检员工号 | ZJ-0271 |
| 判定时间 | 精确到分钟 | 2026-08-12 14:36 |

## 3 填写要求

1. 缺陷类型必须从六类标准缺陷中选，不允许自造名称；确属新类型时标注「待归类」并由技术组确认。
2. 面积占比必须与图像判定结果一致，偏差超过 10% 需附说明。
3. 疑似根因允许填「待排查」，但必须在 24 小时内回填确认结果。
4. 一张工单只记录一个卷号；同一卷多处缺陷在备注中分项列出。

## 4 常见填写错误

- 把「氧化皮压入」写成「氧化铁皮」：类型不标准，统计时会被漏算。
- 面积占比填 < 0.01 而实际为 0：应填 0.01 或标注「微量」。
- 处置方式填「返修」：不标准，应明确到修磨 / 切除 / 降级 / 判废。
- 缺「疑似根因」：工单无法纳入归因统计，视为不合格工单。

## 5 闭环要求

工单闭环必须补齐：处置人、处置完成时间、剩余卷重、复检结论。未闭环工单超过 72 小时，系统自动升级提醒至质量部经理。
